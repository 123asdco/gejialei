📝 任务二 · 提示词与 AI 问答记录

发给 AI 的提示词：

我正在用 Swiper 11 做轮播效果实验台，已经实现了
slide/fade/cube/coverflow/flip/cards 六种效果切换。
现在想添加第 7 种 creative 效果，要求：
- 上一张(prev)：缩小并向左移动，带一点旋转角度，半透明
- 下一张(next)：放大并从右侧进场，像电影画面进场一样
请帮我写出 creativeEffect 配置，包括 prev 和 next 的
translate、rotate、opacity 参数。
另外请解释：prev 的 transform 和 next 的 transform
分别控制什么？百分比是相对谁的？

AI 回答要点：

creativeEffect: {
  prev: {
    shadow: true,
    translate: ['-30%', 0, -500],  // 左移30%、Z轴后退
    rotate: [0, 0, -15],           // Z轴旋转-15度
    scale: 0.7,                    // 缩小到70%
    opacity: 0.4,                  // 半透明
  },
  next: {
    shadow: true,
    translate: ['100%', 0, 0],     // 从右侧100%位置进场
    rotate: [0, 0, 15],            // Z轴旋转+15度
    scale: 1.2,                    // 放大到120%
    opacity: 0.9,
  },
}

追问与自答：

① prev.transform 控制「离开当前位置、成为上一张」时的动画终点状态；next.transform 控制「从等待位置进场、成为当前张」时的起点状态。
② translate 中的百分比是相对于 slide 自身宽度的（如 '-20%' 表示左移自身宽度的 20%）。
③ 把 rotate 的第三个值从 -8 改成 -20，卡片就会转 20 度（更夸张的倾斜）。

② keyboard 键盘控制提示词：

Swiper 11 如何启用键盘控制？我想让用户可以用键盘
左右方向键切换轮播图片，只在轮播在视口内时才响应键盘。
请给出 keyboard 配置的完整写法，并说明 enabled 和
onlyInViewport 两个参数的作用。
keyboard: {
  enabled: true,          // 启用键盘控制
  onlyInViewport: true,   // 仅当轮播在视口内时响应
}

答辩四连问自答：
① keyboard 配置让 Swiper 监听键盘事件，← 切上一张、→ 切下一张。
② AI 第一次只给了 keyboard: true，但 Swiper 11 需要对象形式 { enabled: true }，已改为对象写法。
③ onlyInViewport: true 确保页面上有多个轮播时，只有当前可见的那个响应键盘，避免冲突。
④ 把 autoplay.delay 从 3200 改成 1000，轮播会每秒翻一张，节奏变快。
